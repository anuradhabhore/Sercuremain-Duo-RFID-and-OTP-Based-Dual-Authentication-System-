# Sercuremain-Duo-RFID-and-OTP-Based-Dual-Authentication-System-
Developed SecurePass Duo, an RFID and OTP-based dual authentication system using LPC2148 and GSM. The system verifies an authorized RFID card, generates and sends a one-time password via SMS, and grants access only when the OTP is correctly entered, enhancing security for restricted-access areas.
